⚙ Supabase 配置

配置后所有设备实时同步；未配置则使用本地模式（只本浏览器可见）
格式：https://你的项目ID.supabase.co
从 Supabase → Project Settings → API Keys 复制
📖 第一次用？点开看教程
1. 打开 supabase.com → 注册 → New Project
2. 项目创建后，左侧 Project Settings → API Keys
3. 复制 Project URL 和 publishable key（anon）
4. 左侧 SQL Editor → New Query → 粘贴下方建表 SQL → Run
📋 建表 SQL（点开复制） 
CREATE TABLE health_records (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  ts BIGINT NOT NULL,
  member TEXT NOT NULL,
  category JSONB NOT NULL,
  values JSONB NOT NULL,
  note TEXT DEFAULT '',
  created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_health_records_ts ON health_records(ts DESC);
ALTER TABLE health_records ENABLE ROW LEVEL SECURITY;
CREATE POLICY "public_all" ON health_records FOR ALL
  TO anon USING (true) WITH CHECK (true);
ALTER PUBLICATION supabase_realtime ADD TABLE health_records;

CREATE TABLE body_events (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  ts BIGINT NOT NULL,
  end_ts BIGINT,
  member TEXT NOT NULL,
  category TEXT NOT NULL,
  severity INTEGER DEFAULT 3,
  title TEXT,
  payload JSONB NOT NULL DEFAULT '{}'::jsonb,
  tags TEXT[] DEFAULT '{}',
  note TEXT DEFAULT '',
  created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_body_events_ts ON body_events(ts DESC);
CREATE INDEX idx_body_events_member ON body_events(member);
CREATE INDEX idx_body_events_category ON body_events(category);
ALTER TABLE body_events ENABLE ROW LEVEL SECURITY;
CREATE POLICY "public_all_body" ON body_events FOR ALL
  TO anon USING (true) WITH CHECK (true);
ALTER PUBLICATION supabase_realtime ADD TABLE body_events;

👆 key 仅存在你的浏览器，不上传任何服务器
默认 qwen3.6-flash（支持识图）；识图专用可填 qwen3-vl-plus。qwen-turbo / qwen-vl-plus / qwen3-vl-flash 已下线不可用
